# プログラム一覧サイト

ビルド不要の静的サイトです（HTML、CSS、素の JavaScript だけで、npm は使いません）。このフォルダをそのまま GitHub Pages で公開できます。

## プログラムの登録（いつもの作業）

1. サムネイル画像を `サムネイル/Class1`〜`Class4` のどれかに入れる（16:9 推奨）
   - 対応形式：jpg / jpeg / jfif / jif / jpe / png / gif / webp / avif / bmp / tif / tiff（拡張子の大文字・小文字は問わない）
   - アニメーションGIFは1コマ目を使う。iPhoneの写真（.heic）は非対応なので、jpg などに変換してから入れる
   - 対応していない形式や壊れた画像はスキップし、同期の画面にファイル名を表示する（ほかの画像の同期は続ける）
2. `同期.bat` をダブルクリックする
3. 黒い画面に「同期しました：全 ○ 件」と出たら完了。何かキーを押すと画面が閉じる

同期で行うことは次のとおりです。

- 画像を WebP に変換して `images/programs/` に出力する（詳細ページ用は幅1280px、一覧カード用は幅640px）
- `data/programs.json` を、フォルダの中身に合わせて書き直す
- フォルダから消した画像は、一覧からも公開用の画像からも消える
- 変更のない画像は変換し直さない（全件やり直すときは、コマンドプロンプトで `同期.bat --force`）

並び順はファイル名の順です（`2.jpg` は `10.jpg` より前）。順番を決めたいときは、ファイル名の先頭に `01_`、`02_` のように番号を付けてください。

### タブ（クラス）

- 一覧のタブは「セッション」（全件）と、`サムネイル/` の中のフォルダです。フォルダ名がそのままタブ名になります
- フォルダを追加すればタブが増え、フォルダを消せばタブも消えます（同期後に反映）
- 名前が `.` か `_` で始まるフォルダは無視します（一時的に外しておきたい画像の置き場に使えます）
- 選んだタブは URL に残ります（例: `index.html#class2`）。詳細ページの「← プログラム一覧」で、元のタブに戻ります

### タイトルや説明を付ける

タイトルの初期値はファイル名（拡張子を除く）です。変えたいときは `data/programs.json` の該当する項目を直接書き換えます。書き換えた内容は、次に同期しても消えません。

```json
{
  "id": "class1-c444bbad",
  "class": "class1",
  "title": "ここを書き換える",
  "description": "説明文（改行は \\n）",
  "tags": ["追加のタグ"],
  "source": "サムネイル/Class1/元のファイル名.jpg",
  "image": "images/programs/class1-c444bbad.webp",
  "thumb": "images/programs/class1-c444bbad.thumb.webp"
}
```

| 項目 | 書き換え | 説明 |
| --- | --- | --- |
| `title` | ○ | 詳細ページの見出し。カードの読み上げラベルにも使う |
| `description` | ○ | 詳細ページの説明文（任意） |
| `tags` | ○ | 詳細ページで、クラス名の横に並ぶタグ（任意） |
| `href` | ○ | 指定すると、詳細ページの代わりにこの URL へ移動する（外部 URL は新しいタブで開く。任意） |
| `id` `class` `source` `image` `thumb` | × | 同期のたびに自動で書き直す |

**注意：** 画像のファイル名を変えたり、別のクラスへ移したりすると、別の画像として扱われます（`id` が変わります）。そのため、書き換えたタイトルや説明は引き継がれません。

## ローカルで確認する

JSON を読み込むため、HTML をダブルクリックで開いても一覧は表示されません。簡易サーバーを起動して確認してください。

```
python -m http.server 8000
```

起動したら、ブラウザで http://localhost:8000/ を開きます。VS Code の拡張機能「Live Server」でも確認できます。

## フォルダ構成

```
同期.bat                ダブルクリックで同期（scripts/sync.py を実行する）
サムネイル/Class1〜4/    元画像を入れる場所（フォルダ＝タブ）
index.html              一覧ページ（マイページとプログラム一覧）
program.html            詳細ページ（program.html?id=… で開く）
data/programs.json      一覧データ（同期で自動生成。title などは手で書き換えても残る）
images/                 公開用の画像（同期で自動生成）
src/
  config.js             サイト設定（ロゴ画像のパスなど）
  js/common.js          共通処理（データの読み込み、サムネイル、ロゴ）
  js/list.js            一覧ページの処理（タブ、カード）
  js/detail.js          詳細ページの処理
  styles/base.css       共通スタイル（配色トークン、ヘッダー、カードの基本形）
  styles/list.css       一覧ページのスタイル
  styles/detail.css     詳細ページのスタイル
assets-src/banner.jpg   アクティビティ欄のバナーの元画像（差し替えたら同期する）
assets-src/logo.png     ヘッダーのロゴの元画像（差し替えたら同期する）
scripts/sync.py         同期スクリプト本体
program-list.html       元の仮作成ファイル（参照用）
.nojekyll               GitHub Pages にファイルをそのまま配信させるための空ファイル
```

同期には Python 3 と Pillow が必要です（このPCには入っています。別のPCで使うときは `pip install pillow`）。

## ロゴの差し替え

1. 元のロゴ画像を `assets-src/logo.png` として置く（jpg なども可。上書きでよい）
2. `同期.bat` を実行する。余白の切り落とし、白背景の透過、縮小をして `images/logo.webp` ができる
3. ヘッダー中央に表示される（`src/config.js` の `logo.src` が `images/logo.webp` を指している）

- 表示する高さは `src/config.js` の `logo.height`（今は36px）で変えられます。スマホ幅では、その8割の高さになります
- 横長のロゴでも、左のメニューボタンと重ならない幅まで自動で縮みます
- ダークモードでは、黒い文字が読めるよう、ロゴの後ろに白い角丸の下地を敷きます
- 画像が読み込めなかったときは、仮ロゴ（SVG）が表示されます

## 表示を軽くする工夫

- 一覧カードには、幅640pxの WebP を使う
- `loading="lazy"` で、画面に近づいたカードだけ画像を読み込む
- `decoding="async"` と width/height の指定で、描画の詰まりやレイアウトのずれを防ぐ
- 画像は読み込みが終わってからフェードインする。それまではカードの背景色が表示される

## 動き

- カードにマウスを乗せると少し浮き上がり、画像がわずかに拡大する（マウス操作の端末だけ）
- カードを押すと、押した瞬間にわずかに沈む
- ページを移動するとクロスフェードする（View Transitions に対応したブラウザだけ）
- OS で「視差効果を減らす」を設定している場合は、動きをすべて止める

## GitHub Pages で公開する

1. 同期を実行してから、このフォルダを GitHub のリポジトリに push する
2. リポジトリの Settings → Pages で「Deploy from a branch」を選び、`main` ブランチの `/ (root)` を指定する

パスはすべて相対指定なので、`https://ユーザー名.github.io/リポジトリ名/` のようなサブパスでもそのまま動きます。

## 補足

- 「最近の視聴」は、詳細ページを最後に開いたプログラムを、その端末のブラウザに保存して表示します。まだ何も見ていないときは、先頭のプログラムを表示します。
- リポジトリに含めたファイルは、すべて公開されます（`サムネイル/` の元画像や `program-list.html` も含む）。元画像を公開したくない場合は、`.gitignore` に `サムネイル/*/*` と `!サムネイル/*/.gitkeep` の2行を追加してください（2行目は、空のクラスフォルダを残すための指定です）。サイトの表示に使うのは `images/` の変換済み画像だけなので、表示には影響しません。
